# Pragmatic Translation System - Lab 10

## Quick Start Guide

### Files in this folder:
1. **lab10.ipynb** - Main notebook with all code and implementation
2. **pragmatic_translation_dataset.csv** - Dataset with 10 Hindi sentences
3. **LAB10_DOCUMENTATION.txt** - Complete detailed documentation
4. **translation_comparison.csv** - Results comparison table (generated after running)

### How to Run:
1. Open `lab10.ipynb` in Jupyter Notebook or VS Code
2. Run all cells in order (from top to bottom)
3. View results and analysis

### What This Does:
Builds a smart Hindi-to-English translation system that handles:
- ✅ Idioms (phrases with hidden meanings)
- ✅ Polite requests (respectful sentences)
- ✅ Sarcasm (opposite meaning)
- ✅ Ambiguous words (multiple meanings)

### Simple Explanation:
Regular translators just convert words one-by-one and often get confused.
Our system understands CONTEXT and MEANING, not just words!

**Example:**
- Hindi: "हाथ धो लिए"
- Literal translation: "washed hands" ❌
- Our translation: "gave up" ✅
