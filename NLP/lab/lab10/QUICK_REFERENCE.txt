                          EXAMPLE TRANSLATIONS
================================================================================

1. IDIOM EXAMPLE:
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Hindi:     "हाथ कंगन को आरसी क्या"
   
   Literal:   "Hand to bangle what mirror" ❌
              (Makes no sense!)
   
   Our System: "It's obvious, no need for proof" ✅
              (Correct meaning!)
   
   Interpretation: This is an idiom that means something is self-evident.
                   Literal translation talks about bangles and mirrors which
                   is completely wrong!


2. POLITE REQUEST EXAMPLE:
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Hindi:     "क्या आप कृपया मुझे पानी दे सकते हैं?"
   
   Literal:   "What you kindly me water give can?" ❌
              (Awkward and broken!)
   
   Our System: Adds politeness markers ✅
              (Sounds respectful!)
   
   Interpretation: The Hindi sentence uses "कृपया" (please) and "क्या आप"
                   (could you) which are politeness markers. Our system
                   preserves this respectful tone.


3. SARCASM EXAMPLE:
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Hindi:     "वाह, क्या शानदार काम किया है तुमने!"
   
   Literal:   "Wow, what wonderful work done is by you!" ❌
              (Sounds like praise, but it's not!)
   
   Our System: "Wow, what wonderful work! (said sarcastically)" ✅
              (Shows it's actually criticism!)
   
   Interpretation: Uses positive words like "वाह" (wow) and "शानदार"
                   (wonderful) but actually means the opposite. Without
                   the sarcasm tag, it would be misunderstood completely!


4. AMBIGUOUS WORD EXAMPLE:
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Hindi:     "मैं बैंक जा रहा हूँ"
   
   Literal:   "I bank go ing am" ❌
              (Which bank? River or financial?)
   
   Our System: "I'm going to bank (river bank or financial bank?)" ✅
              (Shows multiple meanings!)
   
   Interpretation: "बैंक" can mean river bank or financial bank. Without
                   context, we can't tell which one! Our system alerts the
                   reader that context is needed.

================================================================================
                          TECHNICAL COMPONENTS
================================================================================

1. DETECTORS (Pattern Matching):
   • Idiom Detector → Looks for known idiom patterns
   • Politeness Detector → Finds respect markers like "कृपया"
   • Sarcasm Detector → Identifies overly positive words
   • Ambiguous Word Detector → Spots words with multiple meanings

2. CLASSIFIER:
   • Takes input sentence
   • Runs all detectors
   • Returns category (priority: idiom > polite > sarcasm > ambiguous)

3. TRANSLATORS (5 modes):
   • translate_literal() → Basic word-by-word
   • translate_idiom() → Replaces with actual meaning
   • translate_polite() → Adds respectful tone
   • translate_sarcasm() → Adds sarcasm indicator
   • translate_ambiguous_word() → Shows multiple meanings

4. MAIN SYSTEM:
   • pragmatic_translate() → Combines classifier + translator
   • Returns improved translation with category info
